# Trainings-Journal

Gemeinsames Gedächtnis von **Morning Health Briefing** und **Daily Wrap-Up**. Ein einziger, fortlaufender Feed:
Beide Routinen lesen diese Datei **vollständig**, bevor sie entscheiden, und hängen danach unten im Verlauf genau
einen neuen Eintrag an. So weiß der Morgen, was am Abend davor festgehalten wurde, und der Abend, was morgens geplant
war.

Regeln:
- Alte Einträge im Verlauf nie löschen oder umschreiben. Nur „Stand“ und „Offene Punkte“ werden jedes Mal aktualisiert.
- Neue Einträge immer unten anhängen, im Format der Vorlage. Höchstens 6 Zeilen, Zahlen konkret.
- Keine Zugangsdaten, Tokens oder Konto-IDs.

Vorlage Morgen:
```
### JJJJ-MM-TT Wt · Morgen
- Tagesform: Ampel …, Bereitschaft …, HRV … ms (Status), Ruhepuls …, Schlaf …:… h / Score …
- Vorschlag: <Einheit> (Garmin-Kalender: ja/nein), weil <kurze Begründung>
- Für heute Abend: <was der Wrap-Up prüfen soll>
```

Vorlage Abend:
```
### JJJJ-MM-TT Wt · Abend
- Gefahren: <Einheit, Dauer, NP oder Ø-Puls, Load, TE aerob/anaerob, Hauptnutzen> oder Ruhetag. Plan erfüllt: ja/teilweise/nein
- Tag: Stress Ø …, Body Battery … → …, Bereitschaft … → …, Erholungszeit … h
- Vorschau: <was in den nächsten Tagen neu oder geändert ist, z. B. „Do jetzt Ruhetag voraussichtlich, 4 × 8 min auf Fr“>
- Für morgen früh: <Hinweis für die Entscheidung>, Schlafenszeit …
```
